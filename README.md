# 不動産総合計算機 (bukken-calc)

株式会社T・K企画 不動産部門で使用する、不動産売買向けの総合計算機(スマホ中心)。

## 公開URL

https://tkkikaku.github.io/bukken-calc/

## 機能 (予定)

スマホ片手で営業・現地で使える各種計算ツール:

1. 坪単価 / 面積
2. 仲介手数料
3. 印紙税
4. 登録免許税
5. 不動産取得税
6. 譲渡所得税
7. 住宅ローン
8. 利回り
9. 諸費用合計
10. 軍用地

## 注意

計算結果はすべて **概算** です。正確な税額は税務署・税理士へご確認ください。
